Web Hosting y Dominios

Para que un sitio web como ARLY pueda estar disponible en Internet, necesita un servicio de alojamiento web y una dirección que permita a los usuarios encontrarlo.

¿Cómo llega una página web a Internet?

Primero se crean los archivos del sitio web, como HTML, CSS, JavaScript e imágenes. Después, estos archivos se colocan en un servidor mediante un servicio de Web Hosting.

Una vez que los archivos están alojados, los usuarios pueden acceder al sitio desde un navegador utilizando una dirección web o dominio.

Tipos de Web Hosting

Hosting compartido

Varios sitios web utilizan los recursos de un mismo servidor. Es una opción sencilla y económica para proyectos pequeños.

VPS

Un servidor virtual privado ofrece recursos más independientes y mayor control que un hosting compartido.

Hosting en la nube

Utiliza varios servidores conectados para alojar aplicaciones y sitios web. Puede adaptarse mejor cuando aumenta la cantidad de visitantes.

Vercel para sitios estáticos

Vercel es una plataforma que permite publicar sitios web y aplicaciones en Internet. Es especialmente útil para proyectos desarrollados con HTML, CSS y JavaScript.

Una página como ARLY puede conectarse a un repositorio de GitHub y publicarse para obtener una dirección web accesible desde Internet.

¿Qué es un dominio?

Un dominio es la dirección que utilizan las personas para acceder a un sitio web. Por ejemplo: 


www.arlyjoyeria.com

El dominio permite identificar y encontrar un sitio sin necesidad de escribir directamente la dirección numérica de un servidor.

Dominio, TLD y subdominio

Un dominio puede estar formado por diferentes partes.

  • Dominio: arlyjoyeria.com
  • TLD: .com
  • Subdominio: tienda.arlyjoyeria.com

¿Qué es el DNS?

DNS significa Domain Name System. Su función es relacionar los nombres de dominio con las direcciones de los servidores donde se encuentran los sitios web.

Cuando una persona escribe un dominio en el navegador, el sistema DNS ayuda a encontrar el servidor correspondiente.

Propagación DNS

Cuando se realiza un cambio en la configuración DNS, la información debe actualizarse en diferentes servidores de Internet.

Este proceso se conoce como propagación DNS. Durante este tiempo, algunos usuarios pueden tardar en ver los nuevos cambios.
