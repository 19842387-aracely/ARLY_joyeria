INVESTIGACIÓN WEB

JavaScript

JavaScript es un lenguaje de programación que permite agregar interactividad y comportamiento dinámico a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas. Permite que una página responda a las acciones realizadas por los usuarios.

Por ejemplo, JavaScript puede utilizarse para mostrar mensajes, cambiar contenido, validar formularios, crear animaciones y responder cuando una persona hace clic en un botón.

HTML, CSS y JavaScript

Estas tres tecnologías cumplen funciones diferentes dentro de una página web:

HTML: crea la estructura y el contenido de la página.

CSS: se encarga del diseño, los colores, tamaños y apariencia.

JavaScript: agrega interactividad y comportamiento.

Variables

Las variables permiten guardar información que puede utilizarse posteriormente en un programa. 


let nombre = "ARLY";
let producto = "Collar";
let precio = 25;

Funciones

Una función es un bloque de código que realiza una tarea específica y puede ejecutarse cuando sea necesario. 


function mostrarMensaje() {
    alert("Bienvenido a ARLY");
}

Eventos

Los eventos permiten que JavaScript responda a acciones realizadas por el usuario, como hacer clic en un botón.

Ejemplo práctico

En ARLY podemos utilizar JavaScript para mostrar un mensaje cuando el usuario presiona un botón. 


function bienvenida() {
    alert("¡Gracias por visitar ARLY!");
