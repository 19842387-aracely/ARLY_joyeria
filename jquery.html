jQuery

jQuery es una biblioteca de JavaScript que facilita la creación de páginas web dinámicas e interactivas.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript creada para simplificar tareas comunes como seleccionar elementos HTML, modificar contenido, manejar eventos y crear efectos visuales.

¿Por qué fue creado?

jQuery fue creado para hacer más sencilla la programación con JavaScript y facilitar el trabajo de los desarrolladores al crear páginas web dinámicas e interactivas.

También ayudó a resolver diferencias de funcionamiento entre distintos navegadores.

El símbolo $ en jQuery

En jQuery, el símbolo $ se utiliza como una forma corta de acceder a los elementos de una página HTML y realizar acciones sobre ellos. 


$("#mensaje").hide();

En este ejemplo, jQuery busca el elemento que tiene el identificador mensaje y utiliza el método hide() para ocultarlo.

Ventajas y desventajas de jQuery

Ventajas

  • Facilita la escritura de código JavaScript.
  • Permite trabajar fácilmente con elementos HTML.
  • Incluye efectos y animaciones sencillas.
  • Fue útil para mejorar la compatibilidad entre navegadores.

Desventajas

  • Puede agregar una dependencia adicional al proyecto.
  • Muchas tareas actuales pueden realizarse con JavaScript moderno.
  • Puede ser innecesario para proyectos pequeños.

fadeIn()

El método fadeIn() permite mostrar un elemento utilizando un efecto de aparición gradual. 


$("#mensaje").fadeIn();

slideToggle()

El método slideToggle() muestra u oculta un elemento utilizando un efecto deslizante. 


$("#mensaje").slideToggle();

jQuery y JavaScript moderno

Actualmente, muchas funciones que antes requerían jQuery pueden realizarse directamente con JavaScript moderno. Sin embargo, jQuery sigue siendo útil para comprender cómo funcionan algunas técnicas de manipulación de páginas web.
