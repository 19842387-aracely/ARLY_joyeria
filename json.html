JSON

JSON significa JavaScript Object Notation. Es un formato ligero utilizado para representar e intercambiar datos entre diferentes sistemas.

¿Qué es JSON?

JSON es un formato de texto utilizado para organizar información de una manera sencilla y fácil de leer. Es muy utilizado en páginas web y aplicaciones para enviar y recibir datos.

Una de sus principales ventajas es que puede ser entendido tanto por las personas como por los programas.

¿Por qué JSON es un estándar?

JSON se convirtió en un formato muy utilizado porque es sencillo, ligero y compatible con muchos lenguajes de programación.

Esto permite que diferentes aplicaciones y servidores puedan intercambiar información de una manera organizada.

Pares clave-valor

Los datos en JSON se organizan principalmente mediante pares de clave y valor. 


{
    "nombre": "ARLY",
    "categoria": "Joyería",
    "pais": "El Salvador"
}

En este ejemplo, nombre, categoria y pais son las claves, mientras que "ARLY", "Joyería" y "El Salvador" son sus valores.

Objetos y arrays

Un objeto JSON utiliza llaves { } para almacenar información mediante pares clave-valor.

Un array utiliza corchetes [ ] y permite almacenar varios valores. 


{
    "productos": [
        "Anillo",
        "Collar",
        "Pulsera"
    ]
}

Objeto JavaScript vs JSON

Aunque se parecen, un objeto de JavaScript y un texto JSON no son exactamente lo mismo. 


// Objeto JavaScript

const joya = {
    nombre: "Anillo",
    precio: 25
};


// JSON

{
    "nombre": "Anillo",
    "precio": 25
}

Un objeto JavaScript es una estructura utilizada directamente dentro del código, mientras que JSON es un formato de texto utilizado principalmente para intercambiar información.

JSON en aplicaciones web

JSON es muy utilizado cuando una página web necesita comunicarse con un servidor o una API.

Por ejemplo, una tienda en línea como ARLY podría solicitar a un servidor la información de sus productos. El servidor podría enviar los datos en formato JSON y JavaScript podría utilizarlos para mostrarlos en la página. 


{
    "producto": "Collar",
    "precio": 35,
    "disponible": true
}
